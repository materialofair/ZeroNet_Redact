# v1.5 开发交付说明

本次实现原计划的五项必选功能。视频手动补漏和多图片批处理队列仍属于未实施的可选项。开发分支为 `feat/v1.5-work`，尚未发布。

## 使用入口

- 编辑器关闭时可保存草稿；重新打开原文件后选择恢复或删除。图片、PDF 和视频均使用加密草稿。保存失败会保留编辑器并提示错误。
- 图片/PDF 编辑器右上角放大镜打开文字搜索。支持重复命中、当前页选择、定位、忽略或保留待处理，PDF 跨页应用为一个撤销步骤。
- PDF 有待处理项时显示页面缩略图和“下一处待处理”；定位会重置缩放并高亮目标。
- 系统分享扩展接收图片和 PDF。扩展只加密暂存文件，用户打开并解锁主应用后完成导入。失败文件保留，可重试。
- 图片/PDF 导出完成页显示处理记录；视频完成面板显示核验后的输出音轨数。元数据说明仅针对检查过的字段，不能代表文件不存在其他敏感内容。

## 分享扩展签名配置

主应用标识 `zeronet.zeroNetRedact`；扩展标识 `zeronet.zeroNetRedact.share`；App Group 为 `group.zeronet.redact`。

发布前需要在开发者账户确认两个 App ID 均有此 App Group 能力，并重新生成对应描述文件。主应用使用 `ShareApp.entitlements`，扩展使用 `ShareExtension.entitlements`。扩展有独立收件箱密钥；不读取主应用文件库密钥。此配置尚未通过真机验证。

支持每次 1–10 个附件，每个不超过 15 MB。不支持视频或网页链接。部分附件成功后失败时，不删除已成功暂存的文件；重新分享剩余附件即可。

## 自动验证

在包含 MuPDF 静态库的开发环境执行：

```sh
xcodebuild -project zeroNetRedact/zeroNetRedact.xcodeproj -scheme zeroNetRedact \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -parallel-testing-enabled NO -only-testing:zeroNetRedactTests test
git diff --check
```

新增测试覆盖加密认证篡改拒绝、旧会话写入撤销、删除原件清理草稿、图片旋转恢复、PDF 跨页撤销、视频设置/时间线、重复文字及短语、导航循环、分享附件限制、导出报告不作未经验证的元数据声明。

2026-09-13 验证结果：完整 `zeroNetRedactTests` 运行成功（`TEST SUCCEEDED`）；1 项真实 Vision 人脸推理测试因模拟器无法创建推理上下文而跳过。主应用和内嵌分享扩展均已通过模拟器构建。`git diff --check` 与项目、扩展 plist、中英文字符串的 `plutil -lint` 检查通过。运行日志位于 `/tmp/zeronet-v15-verified.log`（开发机临时文件，不随仓库分发）。
