# v1.5 开发交付说明

本轮补齐原 P0–P2 清单的功能实现，包含原先标为可选的视频手动补漏、人物片段管理和图片批处理。开发分支为 `feat/v1.5-work`，尚未发布；功能实现与发布前真机验收分别记录。

## 使用入口

- 首页底部标签改为“文件”，顶部仅保留分组菜单、类型筛选和更多菜单一行。分组菜单内可新建分组；筛选显示当前类型，空结果可一键清除。排序与多选位于更多菜单，长按文件菜单及辅助功能操作也可进入多选。切换分组保留类型筛选并清空原多选状态。

- 编辑器关闭时可保存草稿；重新打开原文件后选择恢复或删除。图片、PDF 和视频均使用加密草稿。保存失败会保留编辑器并提示错误。
- 图片/PDF 编辑器右上角放大镜打开文字搜索。支持重复命中、当前页选择、定位、忽略或保留待处理，PDF 跨页应用为一个撤销步骤。
- PDF 有待处理项时显示页面缩略图和“下一处待处理”；定位会重置缩放并高亮目标。
- 系统分享扩展接收图片和 PDF。扩展只加密暂存文件，用户打开并解锁主应用后完成导入。失败文件保留，可重试。
- 图片/PDF 导出完成页显示处理记录；视频完成面板显示核验后的输出音轨数。元数据说明仅针对检查过的字段，不能代表文件不存在其他敏感内容。
- 图片/PDF 编辑器的文字光标按钮打开滑选文字：滑过词语选择、拖动橙色手柄调整最后一个框，放大镜帮助定位；也可展开文字列表选择或移除，再一次性应用并撤销。
- 视频预览下方“添加遮挡”直接打开预置框编辑面板：轻点定位、拖动移动、手柄或宽高滑杆调整大小；默认整个视频，也可从当前位置到结尾或用滑杆选一段。保存后查看实际效果，取消不修改原遮挡。“检查遮挡时间轴”中可再次调整已有区域或删除。框位置固定，不会自动跟随移动；预览和导出共用同一处理管线。
- 人物片段管理保留空间跟踪编号：选中时画面显示带编号的黄色框，可把用户确认属于同一人物的片段归组并统一效果。这不是身份识别；检测交叉或中断时需逐段检查。
- 文件页右上角“更多 → 图片批处理”：选择图片与敏感类型/关键词，一次一个文件识别；暂停后可恢复，失败可重试。每张图片均需进入编辑器复核后导出；批次草稿与普通草稿独立保存。
- 批次使用内容哈希和规则指纹去重，每项固定导出 ID，并以已持久化成品记录恢复成功状态。清除队列不删除原图、草稿或成品；主动创建新批次将产生新的导出记录。
- 单文件导入成功后显示“开始处理刚导入的文件”；编辑器首次提示“识别/选择 → 复核遮挡 → 导出”，可关闭提示。
- 视频完成面板记录实际导出音频模式、实际音轨数及容器元数据项数。元数据项数不表示已经识别或清除了画面中的隐私。

## 分享扩展签名配置

主应用标识 `zeronet.zeroNetRedact`；扩展标识 `zeronet.zeroNetRedact.share`；App Group 为 `group.zeronet.redact`。

发布前需要在开发者账户确认两个 App ID 均有此 App Group 能力，并重新生成对应描述文件。主应用使用 `ShareApp.entitlements`，扩展使用 `ShareExtension.entitlements`。扩展有独立收件箱密钥；不读取主应用文件库密钥。此配置尚未通过真机验证。

支持每次 1–10 个附件，每个不超过 15 MB。不支持视频或网页链接。部分附件成功后失败时，不删除已成功暂存的文件；重新分享剩余附件即可。
