# 图片一键人脸脱敏设计

## 目标

在现有图片编辑器中新增“一键人脸脱敏”：完全离线检测当前图片中的所有人脸，默认全选并使用视频人脸脱敏模块的贴纸预览。用户可以在应用前直接点击一张或多张脸取消遮挡，再次点击可恢复；确认后将所有仍选中的人脸作为一次可撤销操作应用到图片。

成功标准：

- 一次操作能检测并默认选中图片中的全部人脸。
- 应用前可连续取消或恢复任意多张脸。
- 图片与视频共用同一套 9 款贴纸、素材和解锁规则。
- 两款笑脸贴纸免费，其余 7 款继续要求高级版；购买成功后自动选中用户刚才请求的贴纸。
- 图片导出继续使用现有图片/视频共享的每日媒体配额，不新增 SKU、次数或收费入口。
- 检测、预览和导出均在设备本地完成。

## 当前事实

- `SimpleBrushEditor` 已支持图片区域的批量应用、图上命中、移动、缩放、逐个删除和撤销/重做。
- `ImageRedactionEditor` 以 `[EditOperation]` 保存编辑历史，批量加入区域只产生一个撤销快照，并从原图单遍重绘。
- `VideoFaceAnalyzer` 已使用 `VNDetectFaceRectanglesRequest`，并将人脸框按 1.3 倍扩张后裁剪到单位坐标范围，优先避免边缘泄露。
- `VideoRedactionSticker` 定义 9 款贴纸；橙色和蓝色笑脸免费，其余 7 款由 `requiresPremium` / `isLocked` 控制。
- 视频贴纸渲染会先铺不透明背景，再绘制贴纸素材；资源缺失时仍保留不透明遮挡。
- 图片和视频导出均通过 `UsageTracker` 使用每日 3 次的共享媒体配额，高级版通过 `AppState.hasUnlimitedAccess` 绕过限制。

## 方案比较

### 方案 A：应用前选择（采用）

检测后显示全部贴纸预览和可点击边框，默认全选。点击人脸切换“遮挡/排除”，点击“应用”后一次写入编辑历史。

优点：用户在写入编辑历史前即可完成多人排除；一次应用、一次撤销；与“先审查再导出”的产品原则一致。缺点：需要一个短暂的选择态以及明确的选中/排除视觉样式。

### 方案 B：先全部应用，再逐个删除

检测完成后立即写入所有贴纸，用户切换到现有拖拽模式逐个选择并删除。

优点：改动最少。缺点：删除多人需要多次操作；每次删除产生独立历史快照；用户难以区分自动人脸区域与其他手工区域。

### 方案 C：底部人脸列表管理

检测后在底部显示人脸缩略图列表，通过多选列表决定保留哪些遮挡。

优点：密集人脸或小脸更容易精确选择。缺点：需要裁剪、缓存和同步缩略图，增加内存与界面复杂度；首版收益不足。

## 产品交互

### 入口

- 仅在图片编辑时显示“一键人脸”入口；PDF 不显示。
- 入口放在现有效果/检测工具区域，和文字敏感信息检测并列，但使用独立状态，避免将“人脸”混入文字敏感区域模型。
- 检测中禁用重复触发，显示进度指示和“正在本地检测人脸”。

### 检测与选择

1. 用户点击“一键人脸”。
2. 使用当前已归一化方向的原始图片执行一次 Vision 人脸矩形检测。
3. 检测框按视频相同的隐私扩张规则放大 1.3 倍，并转换成图片编辑器的 UIKit 左上原点坐标。
4. 所有人脸默认选中并显示当前贴纸预览；边框/角标表达选中状态，不能只依赖颜色。
5. 点击任意脸切换状态：选中时会应用，排除时仅显示轮廓和“已排除”标识；支持连续切换多人。
6. 底部显示“已选择 X/Y 张脸”，并提供“全选/全不选”“应用 X 张脸”“取消”。
7. “应用”把选中的所有矩形以当前贴纸一次写入编辑历史；0 张时禁用应用。

### 贴纸选择与付费

- 选择态展示与视频相同顺序、名称、素材、锁图标和可访问性文案的 9 款贴纸。
- 默认橙色笑脸。免费用户可使用橙色、蓝色笑脸。
- 免费用户点击锁定贴纸时，保持当前贴纸不变并打开现有 `PremiumView`。
- 购买成功关闭购买页后，自动选中刚才请求的贴纸并刷新全部选中人脸的预览；取消购买则不改变选择。
- 人脸检测本身不收费；收费点保持为高级贴纸与既有导出配额，不新增独立“人脸检测次数”。

### 应用后的编辑

- 每张人脸成为一个普通图片编辑区域，可继续使用现有拖拽、缩放和删除能力。
- 整批一键人脸脱敏是一个撤销步骤；撤销一次移除本批全部人脸贴纸，重做一次恢复。
- 应用后再运行一键人脸检测时，只建立新的候选选择，不自动删除或替换此前操作。若新候选与现有人脸贴纸高度重叠，应过滤重复候选，避免重复叠加。
- 旋转图片沿用现有行为：清除所有已应用遮挡；候选选择态先取消，再执行旋转确认。

## 技术设计

### 共享贴纸领域模型

将视频专属命名的贴纸目录抽成图片/视频共享的人脸贴纸定义，例如 `FaceRedactionSticker`。视频现有选择与付费状态机继续复用该模型；图片建立轻量的选择状态，使用同一 `requiresPremium` 和 `isLocked` 判定，避免两套收费规则漂移。

贴纸素材生成和不透明背景合成提取为共享渲染器。视频渲染器与图片编辑器都调用它：视频输出 `CIImage`，图片在 `CGContext` 的目标矩形中绘制共享贴纸图。资源异常时必须输出不透明兜底色，不能回退为原图。

### 静态图片人脸检测

新增单职责的图片人脸分析器：输入方向已归一化的底图 `CGImage`，将长边下采样到不超过 2048 像素后，在后台任务执行 `VNDetectFaceRectanglesRequest`，输出按 UIKit 坐标“从上到下、同行从左到右”稳定排序的归一化矩形。分析器负责 Vision 左下原点到 UIKit 左上原点的转换、1.3 倍扩张、边界裁剪、过小/无效框过滤和取消检查。使用未烘焙编辑效果的底图检测，避免已应用遮挡导致再次检测漏脸。

检测不复用视频逐帧分析循环；只共享人脸框扩张规则。这样静态图片不引入 AVFoundation、时间线和平滑器依赖。

### 编辑操作

为 `RedactionEffect` 明确增加 `.faceSticker(FaceRedactionSticker)`。`ImageRedactionEditor.renderImage` 在同一单遍合成中处理贴纸，不另存一份已烘焙图片。

批量应用接口沿用现有 `applyRedactions` 的单快照语义。区域查询同时暴露效果类型，供重复检测过滤和 UI 区分自动人脸贴纸与普通涂抹区域使用。候选框与已应用人脸贴纸框的交并比（IoU）达到 0.70 时视为同一张脸并过滤；普通文字/手绘遮挡不参与此过滤。

### UI 状态

图片编辑 ViewModel 持有：检测阶段、候选人脸、已选候选 ID、当前贴纸、待解锁贴纸、错误信息。候选只存在于当前编辑会话内，不写 Core Data；真正点击“应用”后才进入 `ImageRedactionEditor.editHistory`。

选择态的图上命中优先级高于画笔手势，退出选择态后恢复原有画笔/拖拽/缩放交互。检测任务在视图退出、重新触发、旋转或取消时终止，过期结果不能覆盖新状态。

## 状态与异常

- 无人脸：保留当前编辑内容，展示“未检测到人脸，请检查图片或手动脱敏”，不创建空操作。
- 检测失败：保留编辑内容并展示可重试错误；不得把失败解释成“没有人脸”。
- 用户取消检测：退出检测态，不改变图片和历史。
- 图片过大或内存压力：检测使用受控尺寸的分析图，但坐标保持归一化并映射回原图；最终贴纸仍按原图分辨率渲染。
- 贴纸资源缺失：用该贴纸配置的不透明背景色完整覆盖矩形，并在调试构建触发断言。
- 高级版购买取消/失败：保持原免费贴纸和当前人脸选择，不自动应用、不触发导出。
- 导出：继续等待现有在途渲染任务；贴纸在最终 PNG 中不可逆烘焙，导出成功后才扣现有媒体配额。

## 无障碍与隐私

- 所有图标按钮保持至少 44pt 点击区域，支持 Dynamic Type、深浅色和 Reduce Motion。
- 每个人脸候选提供“人脸 N，已选择/已排除，轻点切换”的 VoiceOver 标签；计数变化通过可理解文本表达。
- 检测和渲染均完全离线；日志只记录数量、耗时和几何，不记录或持久化人脸裁剪图。
- UI 持续提醒自动检测可能遗漏，用户应在导出前检查整张图片。

## 验证计划

### 单元测试

- 静态分析器：Vision 左下原点到 UIKit 左上原点转换、1.3 倍扩张、边缘裁剪、方向归一化。
- 选择状态：默认全选、单个/多个切换、全选/全不选、取消不写历史。
- 贴纸策略：图片与视频看到完全相同的贴纸集合及 2 免费/7 高级规则。
- 付费状态：锁定贴纸不替换当前选择；购买成功应用待选贴纸；取消不变。
- 渲染：贴纸区域像素完全不透明、资源缺失兜底、图片与视频共享素材输出。
- 编辑历史：批量应用为单次撤销；应用后可逐个删除、移动、缩放；重复检测不重复加入高度重叠候选。
- 导出：等待最后一次渲染，成功后才扣一次媒体配额。

### UI/手工验证

- 0、1、多人、重叠脸、小脸、靠边脸、横竖拍及带 EXIF 方向图片。
- 免费用户、已购买用户、购买取消、购买成功自动续接。
- 连续取消多人、恢复、全不选、取消选择态、应用后撤销/重做。
- iPhone/iPad、横竖屏、深浅色、超大字体、VoiceOver、Reduce Motion。
- 真机大图内存峰值、检测耗时，以及导出后逐像素抽查遮挡区域无原脸泄露。

## 不在本次范围

- 人脸身份识别、跨图片识别同一个人。
- 为不同人分别选择不同贴纸。
- PDF 页面的人脸检测。
- 云端检测、保存人脸缩略图或建立人脸数据库。
- 修改现有买断 SKU、每日媒体配额或视频大小限制。

## 调研依据

- Apple Vision 的 [`VNDetectFaceRectanglesRequest`](https://developer.apple.com/documentation/vision/vndetectfacerectanglesrequest) 用于定位图像中的人脸矩形。
- [`VNImageRequestHandler`](https://developer.apple.com/documentation/vision/vnimagerequesthandler) 支持以 `CGImage` 和明确方向执行 Vision 请求。
- [`VNFaceObservation`](https://developer.apple.com/documentation/vision/vnfaceobservation) 提供归一化人脸边界框；实现仍需显式转换到当前 UIKit 图片坐标系。

## 回滚

功能入口和候选选择态可独立移除；共享贴纸模型保留视频兼容层，确保回滚图片功能时不影响视频导出。图片贴纸效果仅存在于当前编辑会话和导出结果，不需要 Core Data 迁移。
