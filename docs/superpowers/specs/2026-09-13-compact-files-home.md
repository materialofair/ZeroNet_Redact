# 首页紧凑文件导航

用户已确认采用文件优先方案：取消大标题、横向分组条和常驻类型条，以单行导航承载分组、筛选和更多操作。

## 已实现

- 左侧当前分组作为菜单标题，展开显示全部分组与新建入口，长名称单行截断。
- 右侧筛选菜单默认“全部”；选中类型后直接显示类型名称，不新增筛选栏。
- 更多菜单包含多选、排序、图片批处理、分组管理和引导。
- 文件长按菜单及辅助功能操作支持选择，进入多选后禁用类型切换；完成清空选择。
- 保留右下角添加按钮，底部“导入”标签改为“文件”。
- 筛选无结果显示专用空状态和清除按钮；未筛选的空分组保留导入引导。
- 分组切换沿用现有逻辑：保留类型筛选、结束多选并刷新列表。

## 验证

使用 iPhone 17 Pro / iOS 26.5 模拟器构建并运行。相同窗口中首行文件顶部由约 y=350 上移至 y=180，约释放 170 点空间；这是该设备的观察值。

界面检查通过：分组菜单新建入口、PDF 筛选及当前类型显示、空结果清除、排序子菜单文案、多选进入/计数/退出、添加按钮在空结果仍可见。未在本次操作中删除文件或新建测试分组。跨分组保留筛选由原有 selectGroup 逻辑保证，本轮未修改其行为。

验证命令：`xcodebuild -project zeroNetRedact/zeroNetRedact.xcodeproj -scheme zeroNetRedact -destination 'platform=iOS Simulator,id=72367FCE-DFD3-4F3C-AE6D-2A64BD24976F' -derivedDataPath /tmp/zeronet-v15-main build`；`git diff --check`；中英文 Localizable.strings 的 `plutil -lint`。本轮为视图和文案调整，未新增镜像实现的单元测试。大字体、VoiceOver 真机体验仍属于发布前验收。
