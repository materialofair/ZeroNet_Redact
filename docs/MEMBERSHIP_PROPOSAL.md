# 会员体系调研与优化方案

> 状态：决策 1/2 已确认并落地；双轨订阅与定价调整暂缓
> 关联：视频脱敏会员门槛、免费配额模型、定价矩阵
> 日期：2026-08-03

---

## 一、现状梳理

### 1. 产品与定价

| 项 | 现状 |
|---|---|
| 产品 | `com.zeronet.redact.premium`，非消耗型（一次买断） |
| 价格 | $3.99（≈¥25-28），仅一个档位，无订阅 |
| 权益 | 「无限制脱敏」，宣传文案只提**照片与文档**，未提视频 |
| 免费额度 | 图片 3 次/天 + 文档 3 次/天（两个独立计数器） |

### 2. 配额现状（关键问题）

- `EditorViewModel`：图片走 `canExportImage()`（3/天），PDF 走 `canExportDocument()`（3/天）；
- **视频走 `VideoEditorViewModel`，完全没有配额检查** —— 免费用户视频脱敏**无限制**；
- 拼长图（Stitch）按图片配额计 1 次。

### 3. 结论

当前最贵的计算能力（视频人脸追踪 + 导出）**免费且不限量**，会员只卖「照片+文档」，属于典型的权益倒挂：付费动力弱，服务器/算力成本无保护。

## 二、市场调研结论

### 2.1 免费层限制方式（同类 app 常见做法）

| 方式 | 案例 |
|---|---|
| 每日/每周免费次数 | Censor Photo（每周 3 次）、Text Redact（3 次保存）、Whiteout（有限保存） |
| 文件大小/时长上限 | Clideo（免费 ≤500MB）、万兴播爆（按档位限制单次导出时长） |
| 分辨率上限 | Censor Photo（免费长边 ≤1600px）、视频压缩类（免费仅 720p） |
| 导出水印 | Censor Photo、Whiteout、Clideo（Pro 去水印） |
| 功能子集 | BlurBox（免费仅高斯模糊，Pro 解锁马赛克/PDF/视频/批量） |

### 2.2 定价区间（2026 年 App Store 数据）

**纯图片打码类（低客单）**
- DAMA：高级版 **¥18** 买断
- 模糊照片 AI 打码：月 **¥22** / 年 **¥38** / 终身 **¥68**
- 国际：Radact 终身 $29.99、月 $4.99、周 $2.49

**含视频打码/模糊类（高客单）**
- Deface：月度 **¥22** / 年度 **¥98** / 永久 **¥168**
- AutoBlur：连续包年 **¥148** / 永久买断 **¥198**
- 视频特效大师（全能工具）：周 ¥68 / 月 ¥128 / 永久 ¥268
- 国际 BlurBox：周 $1.99 / 月 $4.99 / 年 $29.99

**结论**：视频能力显著抬高客单价（终身 ¥98-268 vs 纯图片 ¥18-68）；主流结构为**订阅 + 永久买断双轨**。

## 三、问题诊断

1. **权益倒挂**：视频（成本最高）免费且无限 → 免费用户无升级动力，付费用户核心诉求（视频）未在文案体现。
2. **定价偏低**：$3.99 永久买断对标纯图片工具（¥18-68），但产品已含视频能力，客单价至少可对标 Deface/AutoBlur 区间。
3. **只有买断、无订阅**：流失低决策成本用户（不愿一次性付 $3.99 的人没有入口）；市场主流是订阅+买断双轨。
4. **配额口径割裂**：图片/文档独立计数、视频无计数 → 用户难以理解「今天还能用几次」。
5. **宣传与功能不符**：产品描述只承诺「photos and documents」，视频用户不知道自己享受了会员级能力。

## 四、优化方案

### 4.1 免费层：配额模型 + 大视频门槛

**配额（回答「视频次数是否与图片一致」）**

> 已确认并落地：**视频与图片合并为「媒体」配额，合计 3 次/天；文档独立 3 次/天。**

- 理由：视频与图片同属「媒体脱敏」心智；合并配额使「3 次」口径统一、设置页展示简洁（「媒体 2/3 · 文档 1/3」）；图片/视频互占额度自然形成升级压力，且没有把免费额度翻倍到 6+3 造成过度宽松。
- 备选（更宽松）：视频独立 3 次/天（图片 3 + 视频 3 + 文档 3）。若担心合并配额劝退轻度视频用户可选用。

**大视频会员门槛（回答「超过一定大小需会员」）**

> 已确认：**免费用户可脱敏 ≤300MB 的视频；>300MB 的视频需要会员。**（2026-08-03 落地）

- 最终定为 300MB：覆盖约 2-5 分钟的日常分享视频（1080p/4K），免费体验足够宽松，同时更早形成会员转化点。
- 阈值常量：`UsageTracker.freeVideoSizeLimit = 300 * 1024 * 1024`，便于后续调整。
- 实现：`VideoEditorViewModel.export()` 导出前用 `OriginalFile.fileSize` 判断，超限且非会员 → 弹提示并引导打开 PremiumView；配额不足 → 弹每日限制提示。

### 4.2 付费层（暂缓）

> 双轨订阅（月/年 + 永久买断）**暂时不做**，后续推广时再议；当前保持现有 $3.99 一次性买断不变。以下为调研结论存档。

| 档位 | 建议价格（CN / US） | 定位 |
|---|---|---|
| 月度订阅 | ¥6 / $0.99 | 低门槛尝鲜 |
| 年度订阅 | ¥18 / $2.99 | 主力转化档 |
| 永久买断 | ¥28 / $3.99 | 保持现价（$3.99），早期不涨价 |

> 说明：
> - 永久买断由 $3.99 提至 $14.99 幅度较大，但调研显示含视频能力的产品终身价普遍 ≥¥98；若担心老用户/评价，可保留 $3.99 作为限时早鸟价（内购里加一个「限时特惠」非消耗型或直接调整）——**建议在正式上架前定好价格，上架后尽量不回调**。
> - 订阅需在 StoreKit 建 Subscription Group（月度 + 年度两个 auto-renewable subscription），永久仍是 NonConsumable；同一权益由 `hasUnlimitedAccess` 统一判断。

### 4.3 权益与文案更新

- Premium 权益列表增加：**「无限制视频脱敏（任意大小）」**，中英文案同步（StoreKit 产品描述 + PremiumView + 设置页）。
- 免费/会员对照在 PremiumView 中明示：
  - 免费：媒体（图片+视频）3 次/天、文档 3 次/天、视频 ≤500MB
  - 会员：无限次数、任意大小视频、全部格式
- 设置页配额展示改为「媒体 x/3 · 文档 y/3」。

### 4.4 技术实现要点（待确认后实施）

1. ✅ `UsageTracker`：`dailyMediaExports` 统一图片+视频计数（存储键沿用 `dailyImageExports` 避免重置）；新增 `freeVideoSizeLimit = 300MB`。
2. ✅ `VideoEditorViewModel.export`：前置校验（>300MB → 大视频提示 → PremiumView；配额不足 → 每日限制提示）；成功导出后 `recordMediaExport()`。
3. ⏳ `StoreManager` 订阅产品：暂缓。
4. ✅ `EditorViewModel`/`StitchViewModel`/`SettingsView`/`Localizable.strings`（中英）同步更新为媒体口径。
5. ✅ 新增 `video.premium.required.title/message` 等 key。
